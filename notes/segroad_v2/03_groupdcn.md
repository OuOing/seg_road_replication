# GroupDCN：可变形局部特征与轻量分组

## 1. 它在 SegRoadV2 中负责什么

DSA 和 GroupDCN 都使用可变形采样，但分工不同：

```text
DSA：全局信息和长距离依赖
GroupDCN：局部边缘、纹理和道路几何细节
```

SegRoadV2 encoder 的四个 block 都主要由 DSA 和 GroupDCN 组成。四级输出全部送入
decoder 融合，因为道路提取是细粒度任务，既需要浅层边缘，也需要深层语义。

## 2. 普通 3x3 卷积

对于中心位置 `p0`，3x3 卷积使用固定相对位置集合：

```text
R = {(-1,-1), (-1,0), ..., (0,1), (1,1)}
```

论文公式 4：

```text
y(p0) = sum[pn in R] w(pn) * x(p0 + pn)
```

符号含义：

```text
p0：当前输出对应的中心位置
pn：3x3 网格中的一个固定相对位置
x：输入特征图
w：该采样位置的卷积权重
y：输出特征
```

问题是：无论目标是水平道路、斜路还是弯路，九个采样点始终是规则方格。

## 3. DCN：给固定位置增加 offset

论文公式 5：

```text
y(p0) = sum[pn in R] w(pn) * x(p0 + pn + delta_pn)
```

新增的 `delta_pn` 是第 `n` 个采样点的二维偏移。3x3 卷积有 9 个采样点，通常要为
每个位置学习 9 组二维偏移。

```text
普通卷积采样：p0 + pn
可变形卷积：  p0 + pn + delta_pn
```

偏移后的坐标可能不是整数，因此实现通常需要可微插值。offset 不需要人工标签，而是
由最终分割和 PCS loss 通过反向传播学习。

对道路的意义：采样点可以从方形网格移动到道路中心线、边缘或弯曲方向附近。

## 4. DCNv3 中的 group、offset 和 confidence

设输入通道数为 `C`，分为 `G` 组：

```text
C' = C / G
```

论文公式 6 可按下面的概念理解：

```text
y(p0) = sum[g=1..G] sum[pn in R]
        W_g * m_g * x(p0 + pn + delta_p_gn)
```

其中：

```text
delta_p_gn：第 g 组、第 n 个采样点的 offset
m_g：该组采样信息的 confidence，范围 [0,1]
W_g：该组的特征变换
```

offset 决定“在哪里采样”，`m_g` 决定“这次采样有多可信”，两者不是一回事。

论文给出 DCNv3 的 `W_g` 形状为：

```text
W_g: C x C'
```

也就是每组仍从完整的 `C` 通道产生 `C'` 个输出通道。所有组加起来，核心通道映射的
参数规模仍约为：

```text
G * C * C' = G * C * (C/G) = C^2
```

## 5. GroupDCN 怎样降低参数量

GroupDCN 先把输入按通道切成 `G` 组：

```text
x = [x_1, x_2, ..., x_G]
x_g: C' channels
```

每组只处理自己的 `x_g`，论文公式 7 可理解为：

```text
y_g(p0) = sum[pn in R]
          W_g * m_g * x_g(p0 + pn + delta_p_gn)

y(p0) = cat(y_1, y_2, ..., y_G)
```

`cat` 表示把各组结果沿通道维拼接回来。此时：

```text
W_g: C' x C'
```

核心通道映射的参数规模约为：

```text
G * C' * C'
= G * (C/G)^2
= C^2 / G
```

所以分组数为 `G` 时，这部分理论参数量约降为原来的 `1/G`。实际模块还包含 offset、
confidence、归一化等分支，因此完整参数量不会严格等于这个简单比例。

论文还提到 channel-to-batch conversion。实现上可以把：

```text
(B, C, H, W)
-> (B, G, C', H, W)
-> (B*G, C', H, W)
```

让各通道组以扩展后的 batch 形式执行相同类别的可变形操作，再恢复并拼接。具体维度
变换仍应以官方代码为准。

## 6. 一个直观例子

假设：

```text
C = 64
G = 4
C' = 16
```

只比较核心通道映射：

```text
DCNv3：    4 * 64 * 16 = 4096
GroupDCN： 4 * 16 * 16 = 1024
```

GroupDCN 约为前者的 `1/4`，但每组仍然拥有可学习 offset，可以沿不同道路方向采样。

## 7. 论文中的效率证据

论文表 3 给出的部分对比：

| 输入形状 | DCNv3 MFLOPs / 参数(K) | GroupDCN MFLOPs / 参数(K) |
| --- | ---: | ---: |
| `(1,64,128,128)` | 261.10 / 16.11 | 254.80 / 3.92 |
| `(1,128,64,64)` | 197.66 / 48.49 | 127.40 / 7.80 |
| `(1,320,32,32)` | 249.36 / 243.95 | 79.63 / 19.47 |
| `(1,512,16,16)` | 150.08 / 586.86 | 31.85 / 31.13 |

参数下降非常明显；FLOPs 的收益会随通道数和空间尺寸变化，不能简单概括成固定倍数。

## 8. 它为什么适合道路

```text
普通卷积：局部能力强，但固定方形网格不贴合道路
DCN：采样位置可移动，但计算和参数可能较高
GroupDCN：保留可变形局部采样，同时通过分组降低成本
```

它主要改善的是：

```text
细路边缘
斜向和弯曲道路
相邻道路之间的局部区分
固定卷积难以覆盖的有效局部感受野
```

论文 Figure 21 还按 confidence 阈值 `0.8` 可视化了高置信采样点和偏移方向，说明作者
不仅观察输出结果，也检查了 GroupDCN 实际选择哪些空间位置。

## 9. 它的代价和风险

```text
分组过多：组间通道交流可能不足
offset 学偏：可能采向河岸、屋顶等相似纹理
可变形算子：不同硬件和框架上的支持、速度可能不同
低参数量：不等于真实推理一定更快
```

因此除了 Params 和理论 FLOPs，还必须测真实设备上的 latency 和显存占用。

## 10. 与 DSA 的最终区别

```text
DSA
  改变 query 的采样位置
  再做长距离 attention
  负责全局关系

GroupDCN
  改变局部卷积的多个采样位置
  按组提取并拼接局部特征
  负责边缘和几何细节
```

一句话：

```text
DSA 让模型沿道路方向看得更远；
GroupDCN 让模型在道路附近看得更细，同时控制计算成本。
```
